ABOUT

A measured local audio tool.

Auralis keeps capture, processing, and render in separate bounded domains so the audio callback stays predictable.

What this screen reports

Queue depth, callback counters, process RSS/CPU samples, model algorithmic latency, inference percentiles, and total software-pipeline latency come from the running local process. No physical acoustic latency is inferred.

To stop safely, use Stop processing or close the terminal that launched this local UI. AEC, target-speaker extraction, and a virtual microphone are not part of this screen.
